## Summary

Add three new aggregate metrics to `lib/insights.ts` and `InsightsPanel.tsx`: run velocity (last-7-day and last-30-day run counts using `startedAt`), top-slug metrics (by run count and by total cost, both with alphabetical tie-breaking), and average feedback rating (collected from `stages[key].feedback.rating`, filtered to [1,5], rounded to one decimal). The JS mirror `lib/insights.js` must be kept in sync as it is what the test runner imports directly.
