# murmur8 Branding Notes

## Brand Direction

murmur8 should feel like a clean SaaS/docs product with a subtle murmuration identity.

The brand should balance:

- Indie developer personality
- Clear engineering process
- Trust, auditability, and control
- A subtle poetic flock motif

## Core Brand Promise

**Agents that move together.**

Supporting phrase:

**A structured approach to agentic development.**

murmur8 turns feature ideas into specs, stories, tests, and implementation through a structured AI engineering pipeline.

## Emotional Direction

The brand should make people feel:

- This is a clever indie dev tool with personality.
- This makes AI coding feel less chaotic and more controlled.
- This is structured, repeatable, and readable.
- This is fast, but not magic.

## Visual Metaphor

The strongest visual metaphor is a murmuration of starlings.

This should be used subtly:

- Abstract flock marks
- Dots or small bird shapes moving together
- Pipeline-like flow
- Coordinated motion
- Small forms creating a larger shape

The bird/flock idea should not overpower the product. It should support the concept of agents coordinating together.

## Recommended Concept: The Flock Pipeline

A flock of small marks forms a loose `m`, `8`, or forward-moving arrow.

The mark should suggest:

- Multiple agents
- Structured handoffs
- Parallel movement
- Speed without chaos

## Website Visual Style

The site should be light-first with dark sections used for impact.
### Homepage
The homepage should feel clean and documentation-friendly.
Suggested style:
- bg-starling-cloud
- Dark navy text
- Pale cyan panels
- Small flock graphics in the background
- Agent accents used sparingly
### Hero Section
The hero could use a darker block for contrast and brand impact.

## Typography
Use a clean sans-serif paired with a strong monospace.
Recommended options:
Headings: Inter, Geist, or Satoshi-style sans
Body: Inter or system sans
Code: JetBrains Mono, Geist Mono, or IBM Plex Mono

## Brand Language 

Agents that move together.
A structured engineering team inside your CLI.
AI coding with a readable trail.
Not magic. A repeatable process.
From fuzzy intent to tested implementation.
Parallel pipelines, coordinated like a flock.

## Brand Personality

- murmur8 should feel:
- Clean
- Technical
- Trustworthy
- Slightly poetic
- Developer-first
- Process-driven
- Friendly but not childish
- Serious enough for teams and enterprises

## Audience

The main audiences are:
- Solo developers using Claude Code or Copilot CLI
- Enterprise teams that care about audit trails and governance
- Open-source developers who like workflow automation

## Design Principles

- Readable over magical
- The brand should reinforce transparency and process.
- Coordinated over chaotic
- The flock metaphor should show structured movement, not randomness.
- Technical but human
- The named agents add warmth, but the visual identity should remain professional.
- Light-first documentation
- The website should be easy to read and use as a reference.
- Dark moments for brand impact
- Use dark navy sections for hero areas, CLI examples, and workflow diagrams.
